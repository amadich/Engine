# __NAME__

Next.js App Router starter with TypeScript, Tailwind CSS, Radix UI, Motion and
Mynaui icons. The source components adapted from Colly include the original
license in each affected package.

1. In Jeridi Engine, install npm dependencies and run the project. Next.js binds to `127.0.0.1:3000`.
2. Select a package in Component Library and apply any draft settings in Inspector.
3. Install to the suggested folder. Open its preview from Inspector or visit `/library`.
4. Import the installed package's `ConfiguredComponent.tsx` in your app to reuse
   its Inspector settings. Import the underlying primitives directly for custom composition.

For terminal use, run `npm ci`, then `npm run dev` or `npm run build`.

# __NAME__

Spring Boot 3.5.16 / Java 17 / Maven project generated by Jeridi Engine.

- Build and test: `mvn test`
- Run: `mvn spring-boot:run`
- Health endpoint: `GET /api/health` (requires authentication if Security was selected).

The Spring Security starter, if selected, requires configuring authentication.
For a JWT foundation, install the optional Spring JWT Authentication Kit in
the Component Library and supply a strong `JERIDI_JWT_SECRET` environment variable.
No demo secret or production credentials are written by the generator.
